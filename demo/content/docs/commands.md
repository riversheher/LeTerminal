## Navigation Commands

| Command | Description |
|---------|-------------|
| `cd`    | Change directory |
| `ls`    | List contents |
| `pwd`   | Print working directory |
| `back`  | Go up one directory |
| `reset` | Return to homepage |

## Content Commands

Content pages are automatically registered as commands based on your content tree.
