Welcome to the documentation hub. This section covers everything you need to know about setting up, customizing, and extending the terminal portfolio theme.

Whether you're installing the theme for the first time or looking to add custom commands and content pages, the documentation is organised into two main sections:

- {{< colored-text color="#b8bb26" >}}Getting Started{{< /colored-text >}} — A step-by-step guide covering prerequisites, installation, configuration, and customization. Perfect for new users.
- {{< colored-text color="#83a598" >}}Commands{{< /colored-text >}} — A comprehensive reference for every available terminal command, including builtins, config commands, and auto-registered tree commands. Covers keyboard shortcuts and command precedence.

### How to Use This Documentation

The docs section works just like any other part of this terminal. You can navigate into `docs/getting-started` or `docs/commands` by typing the path at the prompt, or simply type `getting-started` or `commands` as commands at the root level. Each page is designed to be self-contained, with cross-references where appropriate.

If you encounter any issues, the troubleshooting section in the Getting Started guide covers common pitfalls and their solutions. For feature requests or bug reports, please open an issue in the project repository.
