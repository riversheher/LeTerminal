Welcome to the blog — a space where I write about what I'm building, learning, and thinking about.

This blog sits at the intersection of {{< colored-text color="#83a598" >}}technology{{< /colored-text >}} and {{< colored-text color="#d3869b" >}}lifestyle{{< /colored-text >}}. You'll find deep dives into web development patterns, practical tutorials for tools like Hugo and HTMX, and personal essays on digital minimalism, productivity, and work-life balance. I believe the best tools are the ones that fade into the background, and the best writing comes from real experience.

Whether you're a seasoned developer or just starting your journey, there's something here for you. I write the way I code — with clarity, intention, and a healthy dose of curiosity.

### Categories

- {{< colored-text color="#83a598" >}}tech{{< /colored-text >}} — Hugo, HTMX, frontend architecture, terminal UIs, and web development patterns. Practical tutorials and architectural deep dives with real code examples.
- {{< colored-text color="#d3869b" >}}lifestyle{{< /colored-text >}} — Digital minimalism, productivity systems, remote work insights, and finding balance in a connected world.

The blog is powered by {{< terminal-link url="https://gohugo.io" >}}Hugo{{< /terminal-link >}}, a static site generator written in Go that builds this entire site in milliseconds. The terminal-inspired theme is a custom build designed to make navigation feel like a proper shell session. If you'd like to explore the source code or read more about the project, check out the {{< terminal-link url="https://github.com" >}}project repository{{< /terminal-link >}}.
