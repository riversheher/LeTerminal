HTMX allows you to access modern browser features directly from HTML, without writing JavaScript.

## Key Concepts

- `hx-get`: Fetch content via GET
- `hx-post`: Submit forms via POST
- `hx-target`: Specify where to swap the response
- `hx-swap`: Control how the swap happens
