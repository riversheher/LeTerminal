### Topics Covered

- {{< colored-text color="#83a598" >}}Hugo{{< /colored-text >}} — Static site generation, content organization, custom shortcodes, partials, and building themes from scratch. Everything from first install to production deployment.
- {{< colored-text color="#8ec07c" >}}HTMX{{< /colored-text >}} — Hypermedia-driven applications, AJAX patterns like click-to-load and infinite scroll, event-driven architecture, and building SPAs without the framework fatigue.
- {{< colored-text color="#fabd2f" >}}Terminal UIs{{< /colored-text >}} — Designing command-line interfaces, terminal emulation in the browser, keyboard-driven navigation, and making the terminal feel like home.
- {{< colored-text color="#fb4934" >}}Web Patterns{{< /colored-text >}} — Frontend architecture, build pipelines, progressive enhancement, and the tools that help us ship better software.
